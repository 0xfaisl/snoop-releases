# SNOOP distribution

SNOOP is an independently maintained, local-first companion for compatible wearable hardware,
based on the [NOOP project](https://github.com/ryanbr/noop). SNOOP is not affiliated with or endorsed
by WHOOP, Inc. It is not a medical device.

This repository contains distribution metadata and required notices only. It has independent Git
history and contains no private SNOOP source tree. No SNOOP release or AltStore/SideStore source is
available yet. Application icons and artwork remain unchanged.

Future reviewed SNOOP builds will be distributed through this repository's releases. Upstream NOOP
changes are brought into SNOOP manually; upstream releases are not a SNOOP update channel.

The inherited license, third-party notices, attribution and disclaimer are retained in `LICENSE`,
`NOTICE`, `ATTRIBUTION.md` and `DISCLAIMER.md`.
